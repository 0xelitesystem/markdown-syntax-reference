# Markdown Syntax

A plain-language reference for practical Markdown: the syntax you actually look up when writing a README, an issue, or docs. It covers headings, emphasis, lists, links, images, code, blockquotes, tables, task lists, and the escaping and line-break gotchas that trip people up. Every rule is shown with its literal syntax.

## The core idea

Markdown is a plain-text formatting syntax that converts to HTML, where a few punctuation characters stand in for tags. You write `# Heading` instead of `<h1>Heading</h1>`, `**bold**` instead of `<strong>`, and `- item` for a list. The source stays readable as plain text, which is why it is used for READMEs, issues, comments, and docs. Most of the disagreements between tools come from edge cases (nested lists, line breaks, tables), not the basics.

## The stance

This reference shows the literal characters, not a rendered preview, because the thing you forget is the exact syntax. It favors the CommonMark and GitHub Flavored Markdown behavior most tools follow, and flags where tools disagree rather than pretending there is one universal rule.
